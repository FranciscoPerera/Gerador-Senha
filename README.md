# Gerador de Senhas Seguras

> Projeto web moderno para geração de senhas seguras e personalizáveis, focado em **segurança, usabilidade e experiência do usuário**.

Desenvolvido com **HTML, CSS (Bootstrap 5) e JavaScript puro (Vanilla JS)**.

---

## Demonstração

Gere senhas fortes de forma rápida e personalizada, ajustando tamanho e tipos de caracteres.  
A aplicação conta com feedback visual em tempo real e funcionalidade de cópia com um clique — sem alert, com interface moderna e fluida.

---

## Funcionalidades

- Geração de senhas seguras e aleatórias
- Controle de comprimento da senha
- Personalização de caracteres:
  - Letras minúsculas (a–z)
  - Letras maiúsculas (A–Z)
  - Números (0–9)
  - Símbolos especiais
- Indicador visual de força da senha
- Cópia da senha com feedback (toast)
- Reset completo das configurações
- Layout responsivo (mobile-first)
